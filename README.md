# 🎈 Data Visualizations for Fulcrum Case Study

[Fulcrum](https://www.withfulcrum.com/) gives AI-Powered products to insurance brokerages. 
One feature they offer is the ability to summarize active policies for their accounts. In this case study, 
I created some policy data visualizations for one of Fulcrum's current accounts, [POMS](https://www.pomsassoc.com/). The data used to generate these visualizations are completely random and only used for visualization purposes.

<!-- [![Open in Streamlit](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)](https://blank-app-template.streamlit.app/) -->

### How to run it on your own machine

1. Install the requirements

   ```
   $ pip install -r requirements.txt
   ```

2. Run the app

   ```
   $ streamlit run streamlit_app.py
   ```
